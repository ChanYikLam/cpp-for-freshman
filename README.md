# C++ 零基础入门（计算机专业大一）

写给计算机专业大一新生的 C++ 自学课程，从零基础讲到指针为止。

**从这里开始**：[打开课程首页](index.html)（双击即可，无需联网、无需装环境）

## 这套课的特点

- **照顾零基础**：每个计算机专有名词都先讲「为什么需要它」，再给定义，最后给代码。
- **每章都能动手**：所有代码都是完整可编译的，章节里给编译命令与预期输出，照着敲就能看到结果。
- **一条主线项目**：一个「学生成绩管理系统」从第 3 章开始逐章长大，学完就能跑出一个真能用的程序。
- **章节按知识点分**：不按教材目录抄，按「学会一个知识点」切，每章 40 分钟以内。

## 怎么用

1. 下载整个文件夹（或压缩包），解压到桌面。
2. 双击 `index.html`，浏览器里就能看全部章节，手机上也能看。
3. 每章末尾都有动手练习，建议边看边在电脑上敲一遍。

## 学习顺序

按首页目录从上到下走即可，前一章是后一章的前提。

## 仓库

本仓库同时保存课程页面的**源文件**（`.learning/` 目录），改课内容后重新构建即可生成新的 `index.html` 与 `lessons/*.html`。
