# C++ 零基础入门（计算机专业大一）

写给计算机专业大一新生的 C++ 自学课程，从零基础讲到**指针**为止。产出是一套**离线可打开、可整体压缩经微信转发**的网页课件。

**从这里开始**：双击 [`docs/index.html`](docs/index.html) —— 无需联网、无需装任何环境。

## 这套课的特点

- **照顾零基础**：每个计算机专有名词都先讲「为什么需要它」，再给定义，最后给代码。不假设你会任何其他编程语言。
- **每章都能动手**：所有代码都是完整可编译的，章节里给编译命令与预期输出，照着敲就能看到结果。
- **一条主线项目**：一个「学生成绩管理系统」从数据与输入输出起步，逐章长大，最后用数组与指针改写核心操作。
- **章节按知识点分**：按「学会一个知识点」切，每章 40 分钟以内，前一章是后一章的前提。
- **代码练习带参考解**：需要亲手敲的章节配 `lab/`，含留白任务与参考解，卡住可以对照。

## 怎么用（给拿到的同学）

1. 下载整个文件夹（或收到的压缩包），解压到桌面。
2. **双击 `docs/index.html`**，浏览器里就能看全部章节；手机浏览器也能看，页面自带目录与上/下一章跳转。
3. 按首页目录从上到下学。每章末尾都有动手练习，**强烈建议边看边在电脑上敲一遍**——只看不敲，指针那一章一定过不去。
4. 需要写代码的章节，配套代码在 `lab/` 下：任务文件里有 `TODO`，自己补完再运行；`lab/*/solutions/` 里是参考解。

## 环境准备

课程以命令行 `g++` 为主，第一章会手把手带装。简版：

- **macOS**：终端里敲 `xcode-select --install`，然后 `g++ --version` 验证。
- **Windows**：装 Dev-C++ 或 VS Code + MinGW-w64；第一章有对照说明。
- **Linux**：`sudo apt install g++`（Debian/Ubuntu 系）。

## 给维护者（改课内容）

**先读 [TOOLS.md](TOOLS.md)**：它说明 `.learning/`（课件源文件）为什么不随仓库发布、以及你接手时该怎么恢复它。

课件不是手写的 HTML，而是「内容文件 → 渲染 → 打包」三段：

1. 改内容：`.learning/subjects/cpp-basics/lessons/<NNNN>-<节点id>.md`（讲解）与同名 `.quiz.json`（题目）。
2. 重新渲染课件页：`python3 -X utf8 -B <root>/scripts/render_lesson.py <科目目录> <节点id>`。
3. 重新生成首页与打包站点：

   ```bash
   python3 -X utf8 -B <root>/scripts/gen_home.py <WS>
   python3 -X utf8 -B build_site.py <WS> .
   ```

   `<WS>` 是学习工作区根（含 `index.html` 与 `.learning/`）。`build_site.py` 会重排目录并改写相对引用，跑完自带断链自检——**发出去之前必须看到「本地引用自检：全部可达」**。

**不要手改 `docs/` 里的任何文件**，下次构建会覆盖。
