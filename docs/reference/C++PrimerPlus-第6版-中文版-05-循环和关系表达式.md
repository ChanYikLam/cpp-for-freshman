3.修改规则

C++在C 循环的基础上添加了一项特性，要求对for 循环句法做一些微妙的调整.

这是原来的句法:

```cpp

statement
```

具体地说，正如本意前面指出的.for结构的控制部分囱3个表达式组成，它们自分号分隔.然而，C++循环允许像下面这样做:

```cpp

```

也就是说，可以在for循环的初始化部分中声明变量.这很方便，但并不适用于原来的句法，因为声明不是表达式.这种一度是非法的行为最初是通过定义一种新的表达式一一声明语句表达式( dec恼甜。，n-sta阳nent expression)一一来合法化的，声明语句表达式不宁静分号声明，只能出现在for语句中。然而，这种调整已经被取消了，代之以将for 语句的句法修改成下面这样:

```cpp

statement
```

乍一看很奇怪，因为这里只有一个分号〈而不是两个分号).但是这是允许的，因为for-init-statement被视为一条语旬，而语句有自己的分号。对于for-init-statement来说，它既可以是表达式语句，也可以是声明.这种句法规则用语句替换了后面跟分号的表达式，语句本身有自己的分号.总之，C忡程序员希望能够在for 循环初始化部分中声明和初始化变量，他们会做C++句法需要和英语所允许的工作.
