指针与数组

本节目标：用指针走完整张成绩表，求出总分与最高分，结果与下标版完全一致

上一课让指针指向一个变量，这一课让它指向一整张表。数组名和指针之间有层关系，说清楚了，遍历数组就有两种写法；说不清楚，指针算术就会变成新的玄学。这一课要亲手用指针把成绩表走一遍。

上手做 留白任务

这一课是实操课，任务与验收标准见 动手任务：指针遍历成绩表，参考解在 solutions/。下面的讲解是按顺序给你铺路的，读一节做一节，别一口气读完再动手。

数组名就是第一个元素的地址

上一课把 &score 打印出来，是一个 0x 开头的数。这一课先做同一件事，只是换成数组。

存成 parr-01.cpp 再编译：

// parr-01.cpp -- 数组名就是第一个元素的地址
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {88, 76, 95, 60, 82};

    cout << "scores[0] 的值是 " << scores[0] << endl;
    cout << "scores[0] 的地址是 " << &scores[0] << endl;
    cout << "scores 本身打印出来是 " << scores << endl;

    cout << "scores[1] 的地址是 " << &scores[1] << endl;

    int *p = scores;        // 把第一个元素的地址交给指针

    cout << "p 里存的地址是 " << p << endl;
    cout << "p 指着的那个元素是 " << *p << endl;

    return 0;
}
$ g++ parr-01.cpp -o parr-01
$ ./parr-01
scores[0] 的值是 88
scores[0] 的地址是 0x16f372290
scores 本身打印出来是 0x16f372290
scores[1] 的地址是 0x16f372294
p 里存的地址是 0x16f372290
p 指着的那个元素是 88

第一行和第三行打印出来是同一个数。&scores[0] 是第一个元素的地址，scores 打印出来也是这个数。

这里有一层容易被忽略的过程：scores 是一个数组，它有 5 个元素；可是在这一行 cout 里，它被编译器换成了「指向第一个元素的指针」。表达式里的数组名会自动做这个转换，转换之后的指针值就是第一个元素的地址。

int *p = scores; 因此不需要写 &：这里的 scores 同样被换成了指向首元素的指针，直接可以赋给 p。

*p 打印出 88，正是 scores[0]。

数组不是指针

自动转换只发生在表达式里。scores 这个对象本身是一个 int 数组：它占 5 个 int 的地方，类型里带着长度信息。转换出来的指针是一个只装地址的东西，类型里没有长度信息。

两者的区别在下一步就会显出来：p 是变量，可以改指向别处；scores 是一个数组对象，scores = p; 编译不过。

图上最后两行是一处常被忽略的差别：scores 和 p 打印出来是同一个数、都能用来取元素，但 p = p + 1; 合法，scores = scores + 1; 编译不过。

差别来自上一节那个自动转换：scores 是一个数组，它在表达式里被换成指针，换出来的那个指针值只是一次转换的结果，没有一个可以写回去的地方，所以数组名不能赋值。p 是一个实实在在的指针变量，它占着自己的格子，随时可以装一个新地址。

指针算术按类型步长走

上一课打印 int 变量地址时，有没有注意到两个相邻 int 的地址相差 4？一个 int 占 4 个格子，所以下一个 int 从编号加 4 的地方开始。

指针加一，走的就是这个距离。指针算术的规则是「往后挪一个它指向的那种类型的对象」；要知道地址上走了多远，就数一数那个类型占几个字节：

指针类型p + 1 落在哪里地址的变化
int *下一个 int+4 字节
double *下一个 double+8 字节
char *下一个 char+1 字节

「往后挪一个元素」和「地址加 4」说的是同一件事的两面：规则按对象走，落在地址上就是加上一个类型的宽度。p + 1 因此不等于「编号加一」——真按编号加一，在 int 数组上会停在前一个元素中间的两个字节上，解出来的值就成了另一个数。

存成 parr-02.cpp 再编译：

// parr-02.cpp -- 指针算术：p+1 走多远，sizeof 量什么
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {88, 76, 95, 60, 82};
    int *p = scores;

    cout << "p     指向的地址是 " << p << "，值是 " << *p << endl;
    cout << "p + 1 指向的地址是 " << (p + 1) << "，值是 " << *(p + 1) << endl;
    cout << "p + 2 指向的地址是 " << (p + 2) << "，值是 " << *(p + 2) << endl;

    cout << "sizeof(scores) 是 " << sizeof(scores) << " 字节" << endl;
    cout << "sizeof(p) 是 " << sizeof(p) << " 字节" << endl;
    cout << "5 个 int 一共占 " << 5 * sizeof(int) << " 字节" << endl;

    return 0;
}
$ g++ parr-02.cpp -o parr-02
$ ./parr-02
p     指向的地址是 0x16d6ee290，值是 88
p + 1 指向的地址是 0x16d6ee294，值是 76
p + 2 指向的地址是 0x16d6ee298，值是 95
sizeof(scores) 是 20 字节
sizeof(p) 是 8 字节
5 个 int 一共占 20 字节

对着地址算一下：294 - 290 = 4，正是 sizeof(int)。换成 double 数组，每一步就是 8。指针算术的步长由它指向的类型决定，这是这一课最容易出错的地方——看到 p + 1 就以为编号加一，程序会读到数据的中间几个字节，解出来的值就成了另一个数。

对指针用 sizeof 量不到数组长度

sizeof(scores) 是 20，那是整张表的大小。sizeof(p) 是 8，那是一个地址的大小，跟数组有几个元素无关。

这一点在后面把数组交给函数时会变成实际的 bug：函数里写 sizeof(数组名) 得到的是 8，不是 20。第 16 章会专门处理这件事。

两种写法做同一件事

有了指针算术，取第 i 个元素就有两种写法：scores[i] 和 *(scores + i)。它们是同一件事的两种记法，p[i] 与 *(p + i) 也一样。

存成 parr-03.cpp 再编译：

// parr-03.cpp -- 用指针走完整张成绩表，求出总分与最高分
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {88, 76, 95, 60, 82};
    int n = 5;

    int total = 0;
    int highest = *scores;          // 打擂台：先让第一个元素站上擂台

    for (int *p = scores; p < scores + n; p++)
    {
        total = total + *p;
        if (*p > highest)
            highest = *p;
    }

    cout << "成绩表：";
    for (int *p = scores; p < scores + n; p++)
        cout << *p << " ";
    cout << endl;

    cout << "总分：" << total << endl;
    cout << "平均分：" << total * 1.0 / n << endl;
    cout << "最高分：" << highest << endl;

    return 0;
}
$ g++ parr-03.cpp -o parr-03
$ ./parr-03
成绩表：88 76 95 60 82 
总分：401
平均分：80.2
最高分：95

这个程序和上一课的下标版算出来的是同一组数：总分 401、平均分 80.2、最高分 95。逐个部分看：

  • for (int *p = scores; p < scores + n; p++)：p 从第一个元素出发，每轮往后挪一个元素；
  • 循环条件是 p < scores + n，也就是「还没走到第 5 个元素之后」。scores + 5 是最后那个元素再往后一格的位置，不能解引用，只用来当终点线；
  • total = total + *p 和 if (*p > highest)：取当前元素，用法和 scores[i] 那版一模一样。

p[i] 这种写法也照样能用，它会被理解成 *(p + i)。所以下面三种写法取到的是同一个元素：

写法读作
scores[i]数组的第 i 个元素
*(scores + i)从起点往后走 i 个元素，取出来
p[i]（p 指向 scores）同上，只是起点换成了指针

*p++ 与 (*p)++

指针自增写进表达式里时，有一个顺序问题值得单独看一眼。

存成 parr-04.cpp 再编译：

// parr-04.cpp -- *p++ 与 (*p)++ 到底差在哪
#include <iostream>
using namespace std;

int main()
{
    int a[3] = {10, 20, 30};
    int *p = a;

    cout << "*p++ 读出来的是 " << *p++ << endl;   // 先取 *p，再让 p 往后走一格
    cout << "走完之后 p 指着 " << *p << endl;

    int b[3] = {10, 20, 30};
    int *q = b;

    cout << "(*q)++ 读出来的是 " << (*q)++ << endl;  // 先取 *q，再把那个元素加一
    cout << "这时 b[0] 变成了 " << b[0] << "，q 还指着 " << *q << endl;

    return 0;
}
$ g++ parr-04.cpp -o parr-04
$ ./parr-04
*p++ 读出来的是 10
走完之后 p 指着 20
(*q)++ 读出来的是 10
这时 b[0] 变成了 11，q 还指着 11
写法先做什么结果
*p++取 *p，然后把 p 往后挪一格读到的是当前元素，指针动了，数据没动
(*q)++取 *q，然后把这个元素的值加一读到的是当前元素，数据变了，指针没动

括号在这里决定加一加在谁身上：*p++ 加的是 p（往后挪），(*q)++ 加的是 *q（那个 int 加一）。两种都常用，写的时候自己想清楚要动的是指针还是数据。

上手做 第 1 步 · 两种写法各写一遍

在 parr-03.cpp 里把指针版再抄一遍，然后把两个 for 循环整段换成下标版（for (int i = 0; i < n; i++) 配 scores[i]），编译运行，确认打印出来的总分、平均分、最高分一个字都没变。

上手做 第 2 步 · 用 *(p + i) 取元素

把第 1 步的指针版改成：指针只指向起点，取元素时写 *(p + i)，循环变量用 i。这一步是把「指针算术」和「循环变量」分开写，你会看到 p 一直没动，动的只是括号里那个数。
