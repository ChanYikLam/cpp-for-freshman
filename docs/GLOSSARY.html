C++ 零基础入门 Glossary

这套课面向计算机专业大一零基础学生，从「第一次写出 Hello World」讲到「指针与数组配合操作数据」。
全课约 18–20 章，产出一个用数组与指针管理学生成绩的小系统。

这份是「规范版」：定义精确、并且标出「不要用哪个说法代替它」，供核对用词与准确含义。

完全没接触过计算机的同学，先看大白话版——同一批词，每个都先拿生活里的东西打比方，
讲清「它是干什么的」，再给准确说法。两份不冲突：看不懂词时翻大白话版，想确认准确说法时看这份。

用词纪律：本文件上下两节都是这门课的规范用词——课件正文、配图、代码注释里的术语一律以本表为准。
学生真的会用某个词之后，把它从「待掌握」挪进「已掌握」；同一个概念全课只用一个说法，别名列在 _Avoid_ 里。

_Avoid_ 里两种写法的含义不同，别混：

  • 标了括号说明的（例如 二进制（专指表达形式，勿混用））＝这是另一个概念，不是禁用词。
    这种词该用的时候照用，只是不能拿来当本术语的同义说法。课件里用到时要说清它指的是什么。
  • 没标括号的（例如 操作符、算符）＝同一个概念的另一种叫法，本课程不用，正文里不该出现。
  • _别检查_: 另起一行 = 这个词另有常用的普通含义，用词检查不该拦它。典型是「参数」：它泛指时是正常用词，而正文里恰恰要解释「为什么不能只说参数」，那是必要的对比说明。

加这条区分的原因：早先 编译 的 _Avoid_ 里列着「运行、执行、翻译」，而这三件事在 C++ 里
恰恰不是编译——零基础学生最需要分清的就是它们。把不同概念写成「避免的别名」，会让学生以为
「编译和运行是一回事」，也会让用词检查把正确的正文判成错的。

待掌握

源文件:
写给人看、给编译器读的纯文本文件，C++ 的源文件习惯以 .cpp 结尾。
Avoid: 源码文件、代码文件、脚本

编译:
把源文件这种「人看得懂、机器看不懂」的文本，翻译成机器能执行的指令的过程。
Avoid: （无；「编译」「编译过程」「编译器」分别是技术、动作、工具，都是本课程的规范用词，别互相替换）
另需分清（这是另一个概念，不是禁用词）: 运行（跑程序，与编译是两件事）、执行（同「运行」）、翻译（描述这个动作本身，不是这门技术的名字）

链接:
把编译产生的若干目标文件，以及程序用到的标准库代码，拼装成一个完整可执行文件的过程。
Avoid: 连接、组装（口语可用，正式表述统一说「链接」）

可执行文件:
链接完成后得到的、可以直接运行的产物；在 macOS / Linux 上习惯以 a.out 或无后缀命名。
Avoid: 执行文件、程序文件
另需分清（这是另一个概念，不是禁用词）: 二进制（指表达形式，勿当同义词用）

标准库:
C++ 官方随编译器一起提供、开箱即用的一批现成代码；本课程用到输入输出、字符串函数、常用数学函数。
Avoid: 官方库、系统库、内置函数（口语可用，正式表述统一说「标准库」）

变量:
内存里一块有名字的存储空间，用来存一个会变的值。
Avoid: 容器、存储单元（口语可用，正式表述统一说「变量」）
另需分清（这是另一个概念，不是禁用词）: 寄存器（硬件里的东西）

数据类型:
规定一块存储空间「能存什么、占多大、怎么解释这些二进制位」的规则；常见的是 int、double、char、bool。
Avoid: 类型（口语可用，正式表述统一说「数据类型」）
另需分清（这是另一个概念，不是禁用词）: 数据格式

运算符:
告诉计算机「对这些值做一个动作」的符号，比如 +、=、==、%。
Avoid: 操作符、算符（口语可用，正式表述统一说「运算符」）

表达式:
由变量、常量、函数调用和运算符组成、能算出一个值的一段代码；a + b * 2 就是一个表达式。
Avoid: 式子、公式（口语可用，正式表述统一说「表达式」）

语句:
一条完整的、以分号结尾的指令；程序就是按顺序执行的一条条语句。
Avoid: 指令行（改用「语句」）
另需分清（这是另一个概念，不是禁用词）: 命令行（指在终端里敲命令的那个界面）

函数:
把一段完成特定任务的代码打包起来、起个名字，需要时按名字调用；打包是为了复用与分工。
Avoid: 方法、子程序、过程（口语可用，正式表述统一说「函数」；「方法」在 C++ 里通常指类成员函数，本课程不涉及）

形参 / 实参:
函数定义里写的、用来接收数据的占位名字叫形参；调用时真正传进去的值叫实参。
Avoid: 参数（讲到具体一侧时不要用；泛指时可用）
别检查: 参数（它另有常用的泛指义，正文里恰恰要解释「为什么不能只说参数」，那是必要的对比说明，不是用词错误）

返回值:
函数执行完交回给调用者的那个结果，用 return 语句交回。
Avoid: 输出值、结果值、返回数据（口语可用，正式表述统一说「返回值」）

值传递:
C++ 调用函数时的默认传参方式：函数拿到的是实参的副本，函数里改动副本不影响原来的变量。
Avoid: 传值、拷贝传参（口语可用，正式表述统一说「值传递」）

作用域:
一个名字（变量、函数）在源代码里「能被用到」的范围；{} 花括号是 C++ 里最基本的范围分界。
Avoid: 可见范围（口语可用，正式表述统一说「作用域」）
另需分清（这是另一个概念，不是禁用词）: 变量生命周期（见下一条：那是「变量什么时候存在」，与作用域不是一回事）

变量生命周期:
一个变量什么时候被创建、什么时候被销毁——局部变量在自己的定义处被创建，在它所在的那对花括号结束时被销毁。
Avoid: 生存期（别的书里这么叫，本课程统一说「生命周期」）
另需分清（这是另一个概念，不是禁用词）: 作用域（那是「名字在源码里能被用到」的范围，是编译期的事；生命周期是「变量在运行时存在多久」）

数组:
把同一类型的多个值排成一排连续存放、共用一个名字、用下标区分的存储方式。
Avoid: 列表、集合、序列（口语可用，正式表述统一说「数组」；这几个词在别的语言里另有含义）

下标:
数组元素的位置编号，C++ 里从 0 开始数。
Avoid: 索引、序号、位置号（口语可用，正式表述统一说「下标」）

C 风格字符串:
以 '\0'（空字符）结尾的一串字符，通常存在字符数组里；cout 顺着它一直打印到 '\0' 才停。
别检查: 字符串（这个术语正是本课要建立的：正文先说「一串字符就是字符串」，再收窄到「本课程讲的是 C 风格字符串」。收窄之前用「字符串」是必要的引入过程，不是用词错误。讲定之后通篇用「C 风格字符串」）
另需分清（这是另一个概念，不是禁用词）: 字符数组（字符串是「以 '\0' 结尾的字符数组」，两者说的角度不同）

内存地址:
内存里每个字节的位置编号，相当于宿舍门牌号；变量住在某个地址上。
Avoid: 地址号（改用「内存地址」）
另需分清（这是另一个概念，不是禁用词）: 指针值（指针里存的内容就是地址，别把两者当同一个东西）

指针:
一个专门用来存内存地址的变量；它的值是地址，不是那个地址上的数据。
Avoid: 指针变量（口语可用，正式表述统一说「指针」）
另需分清（这是另一个概念，不是禁用词）: 地址（指针存的是地址，但「地址」不等于「指针」，就像门牌号不等于写着门牌号的那张纸）
别检查: 地址（这是日常用词，正文里说「变量的地址」是正常的；要避免的是把它当「指针」的同义词用）

取地址运算符 &:
写在变量前面，得到这个变量所在的内存地址。
另需分清（这是另一个概念，不是禁用词）: 引用符（C++ 的引用是另一回事，勿混用）、and（逻辑与运算符 && 里的那个词，与本符号无关）

解引用运算符 *:
写在指针前面，表示「顺着这个地址，去访问那个地址上的数据」。
Avoid: 星号、乘法（写作 * 时同样的符号还表示乘法，含义要按上下文说清）
另需分清（这是另一个概念，不是禁用词）: 取值运算符（请说「解引用」）

空指针:
值为 0（写作 nullptr）的指针，表示「不指向任何有效对象」；使用前判断它能避免踩内存。
Avoid: NULL 指针（NULL 是旧写法，本课程统一写 nullptr）
另需分清（这是另一个概念，不是禁用词）: 空地址
