C++ 零基础入门 Glossary

这套课面向计算机专业大一零基础学生，从「第一次写出 Hello World」讲到「指针与数组配合操作数据」。
全课约 18–20 章，产出一个用数组与指针管理学生成绩的小系统。

用词纪律：本文件上下两节都是这门课的规范用词——课件正文、配图、代码注释里的术语一律以本表为准。
学生真的会用某个词之后，把它从「待掌握」挪进「已掌握」；同一个概念全课只用一个说法，别名列在 _Avoid_ 里。

待掌握

源文件:
写给人看、给编译器读的纯文本文件，C++ 的源文件习惯以 .cpp 结尾。
Avoid: 源码文件、代码文件、脚本

编译:
把源文件这种「人看得懂、机器看不懂」的文本，翻译成机器能执行的指令的过程。
Avoid: 运行、执行、翻译

链接:
把编译产生的若干目标文件，以及程序用到的标准库代码，拼装成一个完整可执行文件的过程。
Avoid: 连接、组装

可执行文件:
链接完成后得到的、可以直接运行的产物；在 macOS / Linux 上习惯以 a.out 或无后缀命名。
Avoid: 执行文件、程序文件、二进制（二进制 专指表达形式，勿混用）

标准库:
C++ 官方随编译器一起提供、开箱即用的一批现成代码；本课程用到输入输出、字符串函数、常用数学函数。
Avoid: 官方库、系统库、内置函数

变量:
内存里一块有名字的存储空间，用来存一个会变的值。
Avoid: 容器、存储单元、寄存器

数据类型:
规定一块存储空间「能存什么、占多大、怎么解释这些二进制位」的规则；常见的是 int、double、char、bool。
Avoid: 类型、数据格式

运算符:
告诉计算机「对这些值做一个动作」的符号，比如 +、=、==、%。
Avoid: 操作符、算符

表达式:
由变量、常量、函数调用和运算符组成、能算出一个值的一段代码；a + b * 2 就是一个表达式。
Avoid: 式子、公式

语句:
一条完整的、以分号结尾的指令；程序就是按顺序执行的一条条语句。
Avoid: 命令行、指令行

函数:
把一段完成特定任务的代码打包起来、起个名字，需要时按名字调用；打包是为了复用与分工。
Avoid: 方法、子程序、过程

形参 / 实参:
函数定义里写的、用来接收数据的占位名字叫形参；调用时真正传进去的值叫实参。
Avoid: 参数（单独说「参数」时含义不清，必须指明是形参还是实参）

返回值:
函数执行完交回给调用者的那个结果，用 return 语句交回。
Avoid: 输出值、结果值、返回数据

值传递:
C++ 调用函数时的默认传参方式：函数拿到的是实参的副本，函数里改动副本不影响原来的变量。
Avoid: 传值、拷贝传参

作用域:
一个名字（变量、函数）在源代码里「能被用到」的范围；{} 花括号是 C++ 里最基本的范围分界。
Avoid: 生存期、可见范围

数组:
把同一类型的多个值排成一排连续存放、共用一个名字、用下标区分的存储方式。
Avoid: 列表、集合、序列

下标:
数组元素的位置编号，C++ 里从 0 开始数。
Avoid: 索引、序号、位置号

内存地址:
内存里每个字节的位置编号，相当于宿舍门牌号；变量住在某个地址上。
Avoid: 地址号、指针值（指针存地址，不是地址本身）

指针:
一个专门用来存内存地址的变量；它的值是地址，不是那个地址上的数据。
Avoid: 指针变量（口语可用，正式表述统一说「指针」）、地址

取地址运算符 &:
写在变量前面，得到这个变量所在的内存地址。
Avoid: 引用符（C++ 的引用是另一个概念，勿混用）、and

解引用运算符 *:
写在指针前面，表示「顺着这个地址，去访问那个地址上的数据」。
Avoid: 星号、乘法（写法相同，含义要按上下文说清）、取值运算符

空指针:
值为 0（写作 nullptr）的指针，表示「不指向任何有效对象」；使用前判断它能避免踩内存。
Avoid: 空地址、NULL 指针（NULL 是旧写法，本课程统一用 nullptr）
