实验一：跑通编译运行循环

本节目标：自己从空白文件写到一个能跑的程序：读入数据、算出结果、打印出来，编译无警告、输出与预期一致。

这一课是验收课

前面四课你已经知道怎么写、怎么编译、怎么读报错，但还没有独立走完过一整条。这次不再有现成代码给你改，从一份空白文件开始。

这次要做出什么

一个小程序，名字和形式都由你定，只要满足三条：

  • 能读入数据（有提示语，说清要输入什么、什么格式）；
  • 算出一个结果；
  • 把结果按一位小数打印出来。

两个题目挑一个，不要两个都做：

题目输入输出用到了哪几课
A · 体温换算一个华氏温度对应的摄氏度，一位小数变量与类型、算术运算、输入输出
B · 三门成绩算平均分三个成绩总分与平均分，平均分一位小数同上，再加变量运算

推荐题目 A：它的换算公式里有除法，正好逼你把整数除法那一课用上。

换算公式（题目 A）：\text{摄氏} = (\text{华氏} - 32) \times \frac{5}{9}

交付物

一份你自己写的 .cpp 源文件，建议叫 temp.cpp（题目 B 叫 average3.cpp 也行）：

  • 编译命令是 g++ -std=c++17 -Wall -Wextra 你的文件名.cpp -o 程序名；
  • 编译没有任何 warning（所以 -Wall -Wextra 不能省）；
  • 运行输出与下面逐字一致；
  • 代码不少于 35 行（含注释与空行）——这不是凑字数，是要你把它写成一份明天还看得懂的文件。

留白任务在 实验一任务，里面有起始文件、输入文件、预期输出与自查清单。

怎么算过

逐条核，每条都能自己验：

  1. 从空白文件开始写出来的，不是改现成的示例；
  2. g++ -std=c++17 -Wall -Wextra 编译通过，没有任何 warning；
  3. 输入 98.6 时打印出摄氏 37.0；输入 104 时打印出摄氏 40.0；
  4. 自己按计算器核过这两个数；
  5. 故意删掉一个分号、重新编译，能说出报错指的是哪个文件、哪一行，再把分号补回去；
  6. 交之前把 lab/exp-1-first-program/自查清单.md 从头核一遍。

第 5 条容易被跳过，但它是这一课真正要验的东西：编译失败不是意外，是这条循环里的正常一步。

自查清单

  • 编译带 -Wall -Wextra，输出里没有 error、也没有 warning。
  • 输入提示语说清了要输入什么、什么格式。
  • 结果是一位小数，不是一长串、也不是整数。
  • 用到的量有名字（不是一串裸数字），换算系数至少有一个写成小数。
  • 自己按计算器核过两组输入的结果。
  • 代码不少于 35 行。

最可能卡在哪

摄氏永远是 0.0

5 / 9 先按整数除法算，结果是 0，再乘什么都没用。把系数写成小数常量：

const double kScale = 5.0 / 9.0;

只要除号两边有一个是小数，整条表达式就走小数规则。

摄氏算成了 66.6

fahrenheit * 5.0 / 9.0 忘了先减 32。括号不能省：

double celsius = (fahrenheit - kOffset) * kScale;
小数位没控住

打印成一长串小数，是少了 std::fixed << std::setprecision(1)；这两个要一起用，<iomanip> 也要 include。

std::cout << std::fixed << std::setprecision(1);
漏了头文件

std::cin 与 std::cout 都要 #include <iostream>；少了它，报错会说找不到这些名字。std::setprecision 在另一个头文件里——那一条报错就是这个提醒。

编译输出里有一堆 warning

-Wall -Wextra 会把编译器能发现的疑点都提醒出来。看到 unused variable 这类警告先别慌，它指的是「这个变量声明了却没人用」——通常是你写了名字但还没用上，或者打错了一个字。

想不起来某个形状了

回去翻课件，0001 到 0004 四课里都有现成的写法可以借鉴：读入的形状在 0004，小数与整数除法的形状在 0003。借鉴不等于抄——把它们按你这个题目的需要重新组织一遍。

卡壳顺序

  1. 读报错：先看文件名与行号，再看那一行的上一行。
  2. 看这一页的「最可能卡在哪」。
  3. 看 任务目录 里的 自查清单.md。
  4. 还是卡住，才对照 lab/solutions/exp-1-first-program/temp.cpp。
