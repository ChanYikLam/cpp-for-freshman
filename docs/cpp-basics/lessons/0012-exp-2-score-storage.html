实验二：存下并统计一批成绩

本节目标：做出能存 10 个成绩、并算出总分、平均分与最高分的程序，编译无警告、输出与预期一致。

这一课是验收课

单个语法点都学过了：数组会声明、循环会写、函数会包。这次把它们串成成绩管理系统的第一个可用版本——给它一批成绩，它吐出三个数字。

这次要做出什么

一个程序，按顺序做四件事：

  1. 用一个数组存下 10 个成绩；
  2. 第一个循环把 10 个成绩读进来；
  3. 第二个循环算出总分与最高分；
  4. 均分用小数算，保留一位小数，最后按「总分、平均分、最高分」三行打印。

两个要求：

  • 成绩个数只写一处：用一个常量表示 10，声明数组、读入循环、统计调用都用它。以后换成 50 个成绩，只改这一行。
  • 两个统计各自写成函数，main 里只留「读数据、调函数、打结果」。

交付物

一份你自己写的 .cpp 源文件，建议叫 scorestats.cpp：

  • g++ -std=c++17 -Wall -Wextra scorestats.cpp -o scorestats 编译通过，没有任何 warning；
  • 运行输出与下面的预期逐字一致；
  • 代码不少于 40 行（含注释与空行）。

留白任务在 实验二任务，里面有起始文件、四份输入、预期输出与自查清单。

怎么算过

逐条核：

  1. 编译带 -Wall -Wextra，没有 error、也没有 warning；
  2. 输入 10个成绩.in 那十个成绩，打印 总分：869、平均分：86.9、最高分：95；
  3. 自己手加一遍总分（92 + 88 + 95 + 79 + 84 + 91 + 76 + 88 + 90 + 86 = 869），与屏幕上的数字一致；
  4. 换 10个相同成绩.in（十个 60）再跑：总分 600、平均分 60.0、最高分 60；
  5. 换 另一批10个.in 再跑，三个数字都对——说明代码里没有写死数字；
  6. 交之前把 lab/exp-2-score-storage/自查清单.md 从头核一遍。

第 4 条最值得跑：十个成绩全一样时，擂主初值写错、边界少一格、比较号写反，都会在这里露出来。

自查清单

  • 数组只开一次、够 10 格，长度只有一个定义处。
  • 两个统计各自在函数里：函数头有返回类型，函数体有 return。
  • 最高分的擂主初值取的是数组的第一个元素，不是 0。
  • 累加器在进循环之前等于 0。
  • 均分用了小数（除法的两个操作数里至少一个是小数）。
  • 循环条件写 i < N，最后一轮下标正好是 N - 1。
  • 结果不对时，是先打印中间值定位，不是直接改代码。

最可能卡在哪

擂主不能随手写 0 
int best = 0;   // 所有成绩都比 0 大时，0 一直站在台上

擂台上的初值要是「表里真实存在的那个数」，所以让第一个元素先站上去，从第二个元素开始挑战。换成十个相同成绩试一次，这一处错立刻显形。

均分被整数除法吃掉 
double average = total / N;      // total 与 N 都是 int，先整除再赋值

小数在这一步就没有了。改成 static_cast<double>(total) / N，或者把总和存成小数。

循环边界少一格

for (int i = 0; i < 4; i++) 配 5 个元素，最后一个成绩永远进不了统计。盯住最后一轮的下标：写 i < N，最后一轮就是 N - 1。

数组开小了

数组开 5 格却按 10 个读入，第九、第十个成绩会写到数组外面去——把旁边的变量悄悄改坏，而且当场不报错。读入之前先确认长度那个常量与数组声明是同一个数。

算错了先别改代码

在循环里打印每一轮的下标与累加结果：

cout << i << " " << scores[i] << " " << sum << endl;

少算的那一格、多算的那个数，一眼就现形。改之前先知道错在哪一步，比来回改快得多。

卡壳顺序

  1. 读报错：文件名、行号、那一行的上一行。
  2. 看这一页的「最可能卡在哪」。
  3. 看 任务目录 里的 自查清单.md。
  4. 回看第 10、11 课（数组、遍历统计）的形状。
  5. 还是卡住，才对照 lab/solutions/exp-2-score-storage/scorestats.cpp。
