内存地址与取地址符

本节目标：把变量的地址打印出来，再用一个指针读出它指向的那个值

第 9 章留下了一个没解释的现象：在函数里把形参改成 100，回到 main 一打印，score 还是 60。当时的说法是「函数拿到的是副本」。这一课从另一个角度回答同一个问题：副本和原件，住在不同的地方。要能说出一份数据住在哪里，才谈得上让函数去改原件。

为什么需要「地址」这个概念

先把上一课那个程序再跑一遍。

存成 addr-00.cpp 再编译：

// addr-00.cpp -- 第 9 章那个没解释的现象
#include <iostream>
using namespace std;

void tryByValue(int x)
{
    x = 100;
    cout << "函数里 x 现在是 " << x << endl;
}

int main()
{
    int score = 60;
    tryByValue(score);
    cout << "回到 main，score 还是 " << score << endl;
    return 0;
}
$ g++ addr-00.cpp -o addr-00
$ ./addr-00
函数里 x 现在是 100
回到 main，score 还是 60

现在换一个问题问：函数里那个 x，和 main 里那个 score，是两个东西还是同一个东西？

它们是两个。调用 tryByValue(score) 的时候，程序另外找了一块地方，把 score 里的 60 抄了一份放进去，函数里改的是这份抄件。要证明这一点，得有一种办法把「这块数据住在哪里」也打印出来。这种办法就是取地址。

内存里的每块地方都有编号

先建立画面。程序运行时用到的数据都放在内存里，内存可以想成一长排编了号的格子，每个格子有一个编号，这个编号就是内存地址。变量就住在这排格子上：一个 int 占 4 个格子，一个 double 占 8 个格子。

这个编号是实实在在的数字，可以打印出来看。

存成 addr-01.cpp 再编译：

// addr-01.cpp -- 把变量住的门牌号打印出来
#include <iostream>
using namespace std;

int main()
{
    int score = 87;
    int other = 92;
    double avg = 88.5;

    cout << "score 的值是 " << score << endl;
    cout << "score 的地址是 " << &score << endl;

    cout << "other 的值是 " << other << endl;
    cout << "other 的地址是 " << &other << endl;

    cout << "avg 的地址是 " << &avg << endl;

    // sizeof 也能量地址本身：一个地址占多少字节
    cout << "存一个地址要 " << sizeof(&score) << " 字节" << endl;

    return 0;
}
$ g++ addr-01.cpp -o addr-01
$ ./addr-01
score 的值是 87
score 的地址是 0x16f5a3b8c
other 的值是 92
other 的地址是 0x16f5a3b88
avg 的地址是 0x16f5a3b80
存一个地址要 8 字节

你机器上打印出来的地址不会和这里一样，每次运行也都会变——地址由系统在程序启动时决定。具体数字不用记，盯住三件事就够了：

  • 地址确实是一个数，写成 0x 开头的一串十六进制数；
  • score 和 other 的地址不一样，各占各的地方；
  • 两个 int 的地址相差 4，两个地址之间隔着的那几个编号，就是它们各占的格子。

写 & 在变量前面，就得到这个变量的地址。& 叫取地址运算符。它不改变变量，只是把「这里住的是谁」这个信息交给你。

地址在 Windows 上和这里不一样

64 位系统上地址写成 0x 加 12 位十六进制数，占 8 字节。用 32 位的 Dev-C++ 编译器时，地址会短一些，形如 0x0061ff2c，sizeof(&score) 是 4。地址的位数和长短不同，但 & 做的事完全一样。

指针：专门用来存地址的变量

地址是一个数。既然变量能存数，就能有一个变量专门用来存地址。这样的变量叫指针。

为什么需要单独一个名字？因为地址和普通数字不一样：它不能拿来加减乘除，它唯一的用途是「到那个地方去」。C++ 用它自己的类型把这件事说清楚——指针的类型写成「它指向的那个东西的类型」加一个 *。

变量类型存地址的变量写成读作
intint *p;p 是一个指针，指向一个 int
doubledouble *q;q 是一个指针，指向一个 double
charchar *r;r 是一个指针，指向一个 char

声明时那个 * 属于类型，不属于变量名。int *p; 和 int* p; 和 int * p; 是同一件事，本课程统一写成 int *p;，把 * 挨着变量名。

类型必须对上：int 变量的地址只能交给 int *，double 变量的地址只能交给 double *。

类型写错，编译器会拦下来

把 double 的地址交给 int *，编译器会告诉你这两个类型对不上：

error: cannot initialize a variable of type 'int *' with an rvalue of type 'double *'

这一条拦得住是好事。类型对不上的话，按地址去读数据时读几个字节、怎么解释这些字节，全都错了。

顺着地址去访问：解引用

有了存地址的指针，接下来要能「按着这个地址，到地方取数据」。写在指针前面的 * 就是做这件事的。它叫解引用运算符，意思是「顺着这个地址，去访问那个地址上的数据」。

同一个 int，两种写法，含义完全不同：

写法含义类型
p指针里存的那个地址（门牌号）地址
*p顺着地址找到的那个 int（房子里的东西）int

存成 addr-02.cpp 再编译：

// addr-02.cpp -- 用一个指针读到它指向的那个变量的值
#include <iostream>
using namespace std;

int main()
{
    int score = 87;

    int *p = &score;        // p 里存的是 score 的地址

    cout << "score 的值是 " << score << endl;
    cout << "score 的地址是 " << &score << endl;
    cout << "p 里存的地址是 " << p << endl;      // 和上一行是同一个数

    cout << "顺着 p 找到的房子装的是 " << *p << endl;   // 87

    *p = 100;               // 按门牌号进屋，把里面的东西换成 100

    cout << "改完之后 score 是 " << score << endl;
    cout << "p 里存的地址还是 " << p << "（没变）" << endl;

    return 0;
}
$ g++ addr-02.cpp -o addr-02
$ ./addr-02
score 的值是 87
score 的地址是 0x16f5a3b8c
p 里存的地址是 0x16f5a3b8c
顺着 p 找到的房子装的是 87
改完之后 score 是 100
p 里存的地址还是 0x16f5a3b8c（没变）

这个程序里有四件事值得逐行对一遍：

  1. &score 和 p 打印出来是同一个数——p 里存的就是 score 的地址；
  2. *p 打印出 87——顺着地址走进去，拿到的是 score 的值；
  3. 给 *p 赋值 100，再打印 score，出来的是 100——这一句改的是 score 本人，p 只是带路；
  4. p 自己存的那个地址一直没变。

第 3 条是整节课的重点。函数里改不动外面那个变量的原因，现在有了另一种说法：函数拿到的是值 60 的一份副本，它手里没有 score 的地址；如果函数拿到的是地址，它就能走到 score 住的地方去改。

用指针改掉外面的数据

把开头那个程序改一处，就能看到「改得动」和「改不动」的差别。

存成 addr-03.cpp 再编译：

// addr-03.cpp -- 同一个变量，值传递改不动，传地址改得动
#include <iostream>
using namespace std;

void tryByValue(int x)          // 形参是 int：拿到的是副本
{
    x = 100;
}

void tryByAddress(int *p)       // 形参是 int *：拿到的是地址
{
    *p = 100;
}

int main()
{
    int score = 60;

    tryByValue(score);
    cout << "值传递之后 score 是 " << score << endl;

    tryByAddress(&score);       // 把 score 的地址交出去
    cout << "传地址之后 score 是 " << score << endl;

    return 0;
}
$ g++ addr-03.cpp -o addr-03
$ ./addr-03
值传递之后 score 是 60
传地址之后 score 是 100

两个函数看着只差一个 *，做的事却完全不同。tryByValue 拿到 60 的副本，改副本；tryByAddress 拿到 score 的地址，顺着地址进屋改原件。第 9 章的疑问到这里就有了答案，而这个答案的用法，第 16 章会接着展开。

一句话预告：引用

C++ 里还有一种写法能让函数直接改到调用方的变量：把形参写成 int &x，调用时照旧写 tryByAddress(score)，不用写 &。那个 & 在这里是另一个概念，叫引用。本课程不展开它，你知道有这么一件东西就够了。

动手把地址打印出来

先看一眼第三个可能被忽略的地址：指针自己也是变量，也住在某个地方。

存成 addr-01.cpp 再编译。这一课的概念都落在两个打印上，自己敲两遍比看两遍熟得快。

练习 第 1 步 · 把三个变量的地址打印出来

打开 addr-01.cpp，再加两个变量：一个 char 和一个 int 数组的前两个元素。把它们的地址也打印出来，看看同一类型的变量地址相差多少。

练习 第 2 步 · 用指针改一次值

在 addr-02.cpp 里加一段：再声明一个 int *q，让它也指向 score（写 q = p; 或 q = &score;）。通过 *q = 77; 改一次值，然后打印 score、*p、*q 三个数，确认它们都是 77。

结论要能自己说出来：p 和 q 是两个不同的指针，存着同一个地址，所以指向同一个变量。

练习 第 3 步 · 把地址与自己的地址都打印出来

在 addr-02.cpp 里加一句 cout << "p 自己的地址是 " << &p << endl;。比较 p 和 &p 两个打印结果：一个是它指向的地址，一个是它自己住的地址，两个数不一样。
