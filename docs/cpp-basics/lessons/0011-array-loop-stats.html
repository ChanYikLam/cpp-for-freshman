遍历数组做统计

本节目标：用循环把 10 个成绩挨个看一遍，算出总分、均分与最高分。

总分、均分、最高分

成绩表存进数组了，接下来要的是三个数字：这一批成绩的总分、平均分，以及最高分是多少。

三件事看着不同，做法是同一个动作：把数组里的元素挨个看一遍，一边看一边记。记总分就把每个元素加到累加器里；记最高分就把「目前为止最大的那个」留在手上，遇到更大的就换掉。

这一课要讲的，就是「挨个看一遍」这套动作在数组上的写法，它也是成绩统计最核心的那段逻辑。

遍历：挨个看一遍

遍历：按顺序访问数组里的每一个元素，每个元素访问一次。

为什么需要这个词：数组有几十个元素，代码里不可能把每个下标都写出来。要表达「从头到尾都过一遍」，就得有一个说法，循环变量正好能把这件事说清楚——让 i 从 0 取到 N - 1，scores[i] 就依次指向每一个元素。

存成 stats-01.cpp 再编译：

// stats-01.cpp -- 遍历：挨个看一遍，把每个成绩打印出来
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {90, 85, 78, 92, 88};

    for (int i = 0; i < 5; i++)
    {
        cout << "第 " << i + 1 << " 个：" << scores[i] << endl;
    }
    return 0;
}
$ g++ stats-01.cpp -o stats-01
$ ./stats-01
第 1 个：90
第 2 个：85
第 3 个：78
第 4 个：92
第 5 个：88

这段代码的形状是后面所有统计的基础：循环变量既当计数器，又当下标。它数到第几个，就访问第几个元素。

累加求和

把遍历的循环体从「打印」换成「加进总分」，就得到总分；总分再除以个数，就是均分。

存成 stats-02.cpp 再编译：

// stats-02.cpp -- 累加求和，再除以个数得到均分
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {90, 85, 78, 92, 88};

    double total = 0.0;
    for (int i = 0; i < 5; i++)
    {
        total += scores[i];
    }

    double average = total / 5;      // total 是小数，除出来的也是小数
    cout << "总分：" << total << endl;
    cout << "均分：" << average << endl;
    return 0;
}
$ g++ stats-02.cpp -o stats-02
$ ./stats-02
总分：433
均分：86.6

两个地方值得说明。

累加器的初值必须是 0。total 在进循环之前等于 0，循环第一轮才有「0 加上第一个成绩」这件事。初值给别的数，总分就从那个数开始往上加。

均分用小数算。total 声明成 double，total / 5 得到的就是小数 86.6。如果 total 写成 int，433 / 5 会做整数除法得到 86，小数部分被丢掉，之后无论怎么打印都找不回来。

分母写什么，取决于你要平均的是哪一批数据。这一课读固定 10 个成绩，分母就是 10；如果程序是「读到结束标记才停」，实际读到的个数与数组长度可能不同，分母就得用实际读到的个数。

打擂台找最高分

找最高分的做法叫打擂台：让一个变量当擂主，手里拿着目前为止最大的那个成绩；剩下的元素依次上台挑战，比擂主大就把擂主换掉。

擂台上的擂主初值不能随手写 0。要是所有成绩都比 0 小，那个 0 会一直站在台上，最后报出一个根本不存在的最高分。稳妥的做法是让第一个元素先站上擂台——它一定真实存在——然后从第二个元素开始挑战。

存成 stats-03.cpp 再编译：

// stats-03.cpp -- 打擂台找最高分
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {90, 85, 78, 92, 88};

    int best = scores[0];            // 先让第一个元素站在擂台上
    for (int i = 1; i < 5; i++)      // 从第二个元素开始挨个挑战
    {
        if (scores[i] > best)
        {
            best = scores[i];        // 挑战者赢了，换它站在擂台上
        }
    }

    cout << "最高分：" << best << endl;
    return 0;
}
$ g++ stats-03.cpp -o stats-03
$ ./stats-03
最高分：92

注意循环从 i = 1 开始：第一个元素已经在台上了，让它再和自己比一次没有意义，结果也不会变。

三件事合成一个

总分、均分、最高分可以在同一趟循环里算出来：总分与最高分都只是在遍历的循环体里多做一件事。

存成 stats-04.cpp 再编译，输入 10 个成绩：

// stats-04.cpp -- 完整版：读入 10 个成绩，算总分、均分、最高分
#include <iostream>
using namespace std;

int main()
{
    const int N = 10;
    int scores[N];

    cout << "请依次输入 " << N << " 个成绩：" << endl;
    for (int i = 0; i < N; i++)
    {
        cin >> scores[i];
    }

    double total = 0.0;
    int best = scores[0];
    for (int i = 0; i < N; i++)
    {
        total += scores[i];
        if (scores[i] > best)
        {
            best = scores[i];
        }
    }

    double average = total / N;
    cout << "总分：" << total << endl;
    cout << "均分：" << average << endl;
    cout << "最高分：" << best << endl;
    return 0;
}
$ g++ stats-04.cpp -o stats-04
$ ./stats-04

84

90

总分：869
均分：86.9

这段程序里三件事各自的分工很清楚：第一个循环负责把数据读进数组，第二个循环负责统计，最后三行负责输出。把读和算分成两个循环，是因为打擂台需要先有第一个成绩当擂主——数据全都读进来了，擂台的初值才有来源。

这就是成绩管理系统的第一块真正能用的东西：给它一批成绩，它吐出三个数字。后面几课的字符串与指针，都会在这张成绩表上继续加工。

两个常见错法

统计程序的错，多半不在语法，而在循环体里那几行的细节。下面两种错法编译都能过、运行也不报错，只是结果不对。

存成 stats-05.cpp 再编译：

// stats-05.cpp -- 反例：找最大值的比较号写反了
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {90, 85, 78, 92, 88};

    int best = scores[0];
    for (int i = 1; i < 5; i++)
    {
        if (scores[i] < best)        // 写成 < 之后，留在擂台上的是最小的那个
        {
            best = scores[i];
        }
    }

    cout << "最高分：" << best << endl;      // 打印出来的其实是 78
    return 0;
}
$ g++ stats-05.cpp -o stats-05
$ ./stats-05
最高分：78
比较号写反

要挑最大的那个，条件是 scores[i] > best：只有当挑战者比擂主大，才换人。写成 < 以后，换人的时机变成了「挑战者更小」，擂台上留下的就成了最小的那个，这个程序打印的「最高分」其实是 78。

这类错误的特征是结果看着像那么回事：78 确实是这五个成绩里的一个，只是取错了。检查的办法是拿一组心里有数的数据跑一遍——取五个成绩，自己先算出最高分。

再存成 stats-06.cpp 再编译：

// stats-06.cpp -- 反例：循环少跑一个元素
#include <iostream>
using namespace std;

int main()
{
    int scores[5] = {90, 85, 78, 92, 88};

    double total = 0.0;
    for (int i = 0; i < 4; i++)      // 只跑到下标 3，最后一个元素没进统计
    {
        total += scores[i];
    }

    cout << "总分：" << total << endl;
    return 0;
}
$ g++ stats-06.cpp -o stats-06
$ ./stats-06
总分：345
边界少算了一个

五个成绩的总分应该是 433，这里算出来 345，少的正是最后一个 88。条件写成 i < 4，循环只走到下标 3。

数组的长度是 5，循环的上界就该跟着 5 走。写成 const int N = 10; 再用 i < N，是为了把长度与边界绑在同一个常量上：以后数组改成 20 个元素，只要改 N 一处，读数据的循环和统计的循环同时跟上，不会漏。

改完代码先别急着怀疑算法，把中间值打印出来看看：把每一轮的下标和累加结果都打印一次，少算的那一格立刻就现形了。
