循环：把重复交给机器

本节目标：用 for、while 和 do-while 三种循环把一批成绩读进来并累加出总分，看清循环变量每一轮的变化。

一个班五十个人

成绩管理系统要读进一班的成绩。上一章我们已经能读进一个人的成绩，也能用 if 给它分档。现在换了个问题：一个班五十个人。

如果照上一章的写法往下写，就得把 cin >> score; 抄五十遍，还要准备 score1、score2、……score50 五十个变量来接。这样写出来的代码，只要有一处要改，就得改五十个地方。

重复是程序里最常见的事情：读进一批数据、把一批数加起来、在一张表里找最大的那个，都是「同一件事做很多遍」。而计算机最擅长的，正是把同一件事准确地做很多遍。前提是，你能把它说清楚。

循环：把重复交给机器

为了能说清「这件事重复做几遍、什么时候停」，「循环」这个词被引进来。

循环：把需要重复执行的语句只写一次，同时给出「什么时候继续、什么时候停下」的规则，让计算机按这条规则反复执行那组语句的语法结构。

被重复执行的那组语句叫循环体。循环里通常还有一个变量，用来记录「现在是第几轮」，它的值每一轮都会变，循环的继续与停止就是依据它来判断的，这个变量叫循环变量。

C++ 里有三种写循环的语法：for、while、do-while。三种都能表达重复，区别在于「初始化、测试、更新」这三件事写在哪里，以及测试发生在循环体的前面还是后面。

写法测试在什么时候做循环体最少跑几轮
for (初始化; 测试; 更新)先测试，为真才执行循环体0 轮
while (测试)先测试，为真才执行循环体0 轮
do { 循环体 } while (测试);先执行循环体，再测试1 轮

表中的「真」「假」，指的是测试表达式算出来的结果。第 6 课的 if 已经在用这套判断，循环只是把同一个判断问了一遍又一遍。

for 循环的三个部分

for 后面括号里由两个分号隔开的三样东西，就是前面表格里的初始化、测试、更新：

for (初始化; 测试; 更新)
    循环体
  • 初始化：只执行一次，通常用来给循环变量设一个起始值。
  • 测试：每一轮开始之前算一次。结果为真，就执行循环体；结果为假，循环结束，程序接着执行循环后面的语句。
  • 更新：每一轮循环体执行完以后做一次，通常用来把循环变量往前推一格。

for 属于入口条件循环：判断放在入口处，测试一开始就是假的话，循环体一次都不执行。下面这个程序把三部分的作用直接打印出来，同时对照两种边界写法的差别。

存成 loops-01.cpp 再编译：

// loops-01.cpp -- for 循环的三个部分，以及两种边界的差别
#include <iostream>
using namespace std;

int main()
{
    cout << "用 i < 5 控制，i 依次取到：";
    for (int i = 0; i < 5; i++)
    {
        cout << i << " ";
    }
    cout << endl;

    cout << "用 i <= 5 控制，i 依次取到：";
    for (int i = 0; i <= 5; i++)
    {
        cout << i << " ";
    }
    cout << endl;

    return 0;
}
$ g++ loops-01.cpp -o loops-01
$ ./loops-01
用 i < 5 控制，i 依次取到：0 1 2 3 4
用 i <= 5 控制，i 依次取到：0 1 2 3 4 5

同一个起始值，把 < 换成 <=，循环就多跑了一轮。这是循环里最容易写错的一处，后面还会专门说。

用循环读入一批成绩

把重复交给机器以后，「读进一批成绩并累加」就变成了几行：读出人数，循环那么多次，每轮读一个数加进总分。

存成 loops-02.cpp 再编译，输入 5 个成绩试试：

// loops-02.cpp -- 读入已知个数的一批成绩，累加出总分
#include <iostream>
using namespace std;

int main()
{
    int n;
    cout << "请输入成绩个数：";
    cin >> n;

    double sum = 0.0;
    for (int i = 0; i < n; i++)
    {
        double score;
        cin >> score;
        sum += score;
    }

    cout << "共 " << n << " 个成绩，总分 " << sum << endl;
    return 0;
}
$ g++ loops-02.cpp -o loops-02
$ ./loops-02
请输入成绩个数：5
90
85
78
92
88
共 5 个成绩，总分 433

读这段代码时注意两处。第一，sum 在进循环之前必须是 0，它相当于一个「累加器」，每读进一个成绩就往里加一次。第二，sum += score 是 sum = sum + score 的简写：把右边的值算出来，与左边变量原来的值相加，结果存回左边那个变量。+= 这组写法叫组合赋值运算符，除了 +=，还有 -=、*= 等等；累加时写这一种就够了。

int n 与 i < n 的搭配还有一个好处：到数组那一课，这行代码不用改一个字，就能从 5 个成绩换成 50 个。

while：先判再做

上面的程序要求事先知道有几个成绩。真实场景未必这么配合：从一个文件里读成绩，读到文件末尾才知道有几个；让使用者一条一条敲，敲到某个约定的数才算完。这类「事先不知道要跑几轮」的重复，习惯上用 while。

while：只有测试和循环体两部分、每轮开始前先测试的循环。它可以看成省略了初始化与更新的 for。

存成 loops-03.cpp 再编译。这个程序约定：读到 -1 就停。

// loops-03.cpp -- while 循环：读到 -1 为止，事先不知道有几个成绩
#include <iostream>
using namespace std;

int main()
{
    double sum = 0.0;
    int count = 0;
    double score;

    cout << "逐条输入成绩，输入 -1 表示结束：" << endl;
    cin >> score;
    while (score >= 0)
    {
        sum += score;
        count++;
        cin >> score;
    }

    cout << "共 " << count << " 个成绩，总分 " << sum << endl;
    return 0;
}
$ g++ loops-03.cpp -o loops-03
$ ./loops-03
逐条输入成绩，输入 -1 表示结束：
90
85
78
-1
共 3 个成绩，总分 253

这段代码的形状值得记下来：先读一次，再判断，循环体里再读一次。为什么读的语句出现两次？因为「读到的是什么」决定了要不要进循环体，所以第一次读必须发生在测试之前；进了循环体以后要处理下一个数，所以末尾还要再读一次。循环结束时的那个 -1 不参与累加，它只是结束标记。

while 与 for 之间有个容易踩的差别：for 的初始化里可以声明循环变量（for (int i = 0; ...)），while 的测试外面声明。所以 while 里的循环变量，在循环结束以后仍然可以访问。

do-while：先做再判

第三种写法把测试挪到循环体的后面。

do-while：先执行一次循环体，再测试，结果为真就回到循环体开头再来一轮的循环。因为第一次执行循环体之前没有测试，这类循环的循环体至少跑一轮，属于出口条件循环。

存成 loops-04.cpp 再编译，输入与上一个程序完全相同的内容：

// loops-04.cpp -- do-while 循环：先读一次，再判断要不要继续
#include <iostream>
using namespace std;

int main()
{
    double sum = 0.0;
    int count = 0;
    double score;

    cout << "逐条输入成绩，输入 -1 表示结束：" << endl;
    do
    {
        cin >> score;
        if (score >= 0)
        {
            sum += score;
            count++;
        }
    } while (score >= 0);

    cout << "共 " << count << " 个成绩，总分 " << sum << endl;
    return 0;
}
$ g++ loops-04.cpp -o loops-04
$ ./loops-04
逐条输入成绩，输入 -1 表示结束：
90
85
78
-1
共 3 个成绩，总分 253

同样的输入、同样的输出，但读成绩的语句只写了一次：do 里面读，while 那里判断。它比 loops-03.cpp 简洁，代价是循环体必然会跑一轮——测试里判断的那个 score，正是这一轮读进来的。

两种循环的差别，在于判断站在循环体的哪一侧：

提前结束与跳过本轮

循环跑起来以后，有两种临时的需求：一种是想在满足某个条件时提前收工，另一种是想跳过某一轮剩下的活儿、直接开始下一轮。C++ 用两个关键字管这两件事。

  • break：写在循环体里，执行到它，整个循环立刻结束，程序接着执行循环后面的语句。
  • continue：写在循环体里，执行到它，本轮剩下的语句不再执行，直接跳到更新与下一次测试。

存成 loops-05.cpp 再编译：

// loops-05.cpp -- break 与 continue：一个提前结束，一个跳过本轮
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 10; i++)
    {
        if (i % 3 == 0)
        {
            continue;              // 跳过后面的输出，直接进入下一轮
        }
        if (i == 8)
        {
            break;                 // 整个循环到此结束
        }
        cout << i << " ";
    }

    cout << endl << "循环结束" << endl;
    return 0;
}
$ g++ loops-05.cpp -o loops-05
$ ./loops-05
1 2 4 5 7
循环结束

输出里没有 3 和 6（continue 把这两轮剩下的输出跳过了），也没有 8、9、10（i 到 8 时 break 让整个循环提前结束，后面几轮根本没发生）。

break 与 continue 都只管自己所在的那一层循环，循环外面的语句不受影响。

边界写 < 还是 <=

循环次数的错误，多半出在测试那一行。一个可用的做法是：盯住循环变量最后一轮的值。

  • 从 0 开始数，数 n 个：for (int i = 0; i < n; i++)，最后一轮 i 是 n - 1。
  • 从 1 开始数，数到 n 为止：for (int i = 1; i <= n; i++)，最后一轮 i 是 n。

两种写法都对，但它们的起始值必须与 <= 还是 < 配成一套。把 loops-01.cpp 里两个循环的输出对照一下就能看出后果：i < 5 让 i 走到 4，i <= 5 让 i 走到 5。换成读成绩的程序，这一格之差就是「少读一个成绩」或者「多算一个根本没有的成绩」。

循环变量的两处自觉

写循环时养成两个习惯，能挡掉大部分这类错误：

  • 循环体里别顺手改循环变量。i 该在「更新」那一格变，在循环体里再改一次，循环次数就与你想的对不上了。
  • 数清楚最后一轮的值。想不明白就把 i 打印出来跑一次，比盯着屏幕推演快。

转不停的死循环

如果循环变量一直不变，测试条件就永远为真，程序会卡在循环里出不来。这时终端上会一行一行地刷屏，只能按 Ctrl+C 强行掐掉。

存成 loops-06.cpp，它编译得过，但不要去运行：

// loops-06.cpp -- 反例：循环体里忘了更新循环变量
#include <iostream>
using namespace std;

int main()
{
    int i = 0;
    while (i < 5)
    {
        cout << "第 " << i + 1 << " 次循环" << endl;
        // 这里本该有 i++，漏掉了：i 一直是 0，条件永远成立
    }

    cout << "循环结束" << endl;
    return 0;
}
转不停的循环

这个程序的问题不在语法，而在循环体里少了一句 i++：i 一直是 0，i < 5 永远为真，第 1 次循环 会一直打印下去，循环结束 那一行永远轮不到。

while 和 do-while 最容易出这个问题——它们的更新写在循环体里，不像 for 那样有固定的第三格。写完循环后回头问一句：循环变量在这一轮里变了吗？

还有一种更隐蔽的写法会转不停：在 while 循环里用 continue 跳过了更新语句，i 一样不会再变，后果与忘记 i++ 完全相同。for 循环不受这个影响：continue 之后，更新那一格照样会执行。
