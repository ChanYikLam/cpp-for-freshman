# 实验三任务：用指针改写核心操作

**这一课是这门课的终点验收**：把成绩管理系统里求平均、找最高、排序这几个核心操作
**全部改写成指针版本**，并与原来的下标版本对照结果。

**交付物**：一份自己写的 `pointerstats.cpp`，四个函数都以指针传参，输出与预期一致；
编译无警告、代码不少于 45 行（含注释与空行）。

**完整任务书**：同名的课件页 `实验三：用指针改写核心操作`（`lessons/0018-exp-3-pointer-rewrite.html`）
里有验收标准、自查清单与「最可能卡在哪」。

## 这个程序要做出什么

成绩表写在代码里（`{88, 76, 95, 60, 82}`），然后：

1. 用指针遍历把原表打印出来；
2. `averageOf(const int *p, int n)` 交回平均分（一位小数）；
3. `highestOf(const int *p, int n)` 交回最高分；
4. `sortDescending(int *p, int n)` **就地**把表按从大到小排好；
5. 再打印一遍排好序的表。

**四个环节全部用指针**：遍历用 `p++` 或 `p[i]`，函数参数是指针，排序交换的是指针
指着的值、不是指针本身。

## 预期输出

```term
$ ./pointerstats
原成绩表：88 76 95 60 82 
平均分：80.2
最高分：95
排好序：95 88 82 76 60 
```

第一行与最后一行末尾各有一个空格（每个成绩后面跟一个空格），这不影响对照。

自己核一遍：88 + 76 + 95 + 60 + 82 = 401，401 ÷ 5 = 80.2；从大到小排是 95 88 82 76 60。

## 要点

- **遍历用指针**：`for (int *p = scores; p < scores + N; p++)`，取元素写 `*p`。
- **函数参数是指针，长度另传**：`averageOf(scores, N)`，调用处不写 `&`。
- **只读的函数标 `const`**，要改数据的（排序）不标。
- **排序交换的是值**：`int temp = *a; *a = *b; *b = temp;`。写成交换两个指针变量，
  数组一个元素都不会动。
- **每一步都先判空**：`if (p == nullptr || n <= 0) return ...;`
- **不要用 `sizeof(形参)` 求长度**：函数里那个 `p` 是指针，量出来是地址的大小。

## 卡住了怎么办

按这个顺序来：

1. **读报错**：文件名、行号、那一行的上一行。
2. **看第 15、16、17 课**（`0015`、`0016`、`0017`）：指针遍历、指针参数、判空与边界。
3. **看 `自查清单.md`**。
4. 还是卡住，才去看 `lab/solutions/exp-3-pointer-rewrite/pointerstats.cpp`。

**排序卡住时先别写代码**：拿五个数在纸上走一遍「每一轮把最大的换到前面」，
确定每一轮该动哪两格，再写。

## 常见现象对照

| 你看到的 | 多半是什么 |
| --- | --- |
| 排好序那一行和原表一样 | 排序函数里没做事，或者交换的是两个指针变量、不是它们指着的值 |
| 排好序是 60 76 82 88 95 | 比较方向反了，排成了从小到大 |
| 平均分是 80 | 整数除法：均分要用小数算 |
| 平均分是 0、最高分是 0 | 函数里的 `return` 漏了，或者函数体是空的 |
| 程序崩了（段错误 / 窗口闪退） | 解引用了空指针，或者循环走过了数组末尾 |
| 循环走飞、打印出一长串 | 函数里用 `sizeof(p)` 当长度 |
