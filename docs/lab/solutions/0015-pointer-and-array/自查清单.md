# 自查清单：指针遍历成绩表

**每一条都能自己验。**

## 一、编译与运行

- [ ] `g++ -std=c++17 -Wall -Wextra pointerstats.cpp -o pointerstats` 没有任何 `error`，也没有 `warning`。
- [ ] `./pointerstats` 打印四行，程序正常结束（不是崩掉）。

## 二、逐行对输出

- [ ] 第 1 行是 88 76 95 60 82，与代码里那组成绩一致。
- [ ] 第 2 行是 `指针版总分：401`。
- [ ] 第 3 行是 `*(p + i) 版总分：401`——**两个数字必须相同**。
- [ ] 第 4 行是 `*(p + i) 版平均分：80.2`。
- [ ] 自己手加一遍：88 + 76 + 95 + 60 + 82 = 401；401 ÷ 5 = 80.2。

## 三、必须能拦住的情况

- [ ] 把成绩表改成 `{100, 100, 100, 100, 100}`，两个总分都变成 500、平均分变成 100.0。
- [ ] 把成绩表换成 6 个成绩、长度常量跟着改成 6，两遍都还对——**两处都没有写死 5**。
- [ ] 第一遍的循环条件写 `p < scores + n` 时程序不崩；故意改成 `p <= scores + n` 再跑一次，看到它多读了一格（记住：跑完记得改回来）。
- [ ] 在循环里加一句打印 `p`，确认每轮地址涨 4（`int` 的宽度），不是涨 1。

## 四、代码本身

- [ ] 第一遍用指针自增走表（`p++`），取元素写 `*p`。
- [ ] 第二遍里 `p` 一次都没动，取元素写 `*(p + i)`，动的是 `i`。
- [ ] 两个循环的长度都用同一个常量，没有一个写死的 5。
- [ ] 平均分那一步有一个操作数是小数。
- [ ] 没有哪一处解引用了 `scores + n`。

## 五、交之前问自己一句

「这两遍写法，为什么算出来的总分必须一样？」说得出「同一个起点、同一个步长，只是记法不同」，这一课就过关了。
