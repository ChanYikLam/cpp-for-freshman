# 自查清单：实验二 · 存下并统计一批成绩

交之前逐条核。**每条都能自己验。**

## 一、编译

- [ ] `g++ -std=c++17 -Wall -Wextra scorestats.cpp -o scorestats` 退出码是 0。
- [ ] 没有 `error`，也没有 `warning`。

## 二、逐组对输出

- [ ] `./scorestats < 10个成绩.in` → `总分：869` / `平均分：86.9` / `最高分：95`
- [ ] `./scorestats < 10个相同成绩.in` → `总分：600` / `平均分：60.0` / `最高分：60`
- [ ] `./scorestats < 另一批10个.in` → `总分：779` / `平均分：77.9` / `最高分：100`
- [ ] 每一组都自己手算过总分（最高分扫一眼就能找到）。

## 三、必须能拦住的情况

- [ ] 最高分出现在第一个位置时也对。
- [ ] 最高分出现在最后一个位置时也对。
- [ ] 十个成绩全都一样时，最高分等于那个数（擂主初值没写错）。
- [ ] 把某个成绩改成带小数的（例如 `87.5`），总分与平均分跟着变；数组类型选得对不对，这一条看得出来。
- [ ] `./scorestats < 第一个不是数字.in`：程序不会安静地打出一组假成绩。把实际现象记下来，并说得出它与正常输入差在哪。

## 四、代码与交付物

- [ ] 代码不少于 40 行（含注释与空行）。
- [ ] 数组只开一次、开够 10 格；次数用常量表示，声明与所有循环都用同一个常量。
- [ ] 两个统计各自在函数里，函数头有返回类型、函数体有 `return`。
- [ ] 擂主初值取的是数组的第一个元素。
- [ ] 累加器进循环之前等于 0。
- [ ] 均分用了小数。
- [ ] 循环条件写 `i < N`，没有哪一处越界。

## 五、收尾

- [ ] 这份程序与实验一的程序放在一起，都是能编译能跑的完整源文件。
- [ ] 说得出「如果成绩换成 20 个，要改哪几处」——答案应该只有一处常量。
