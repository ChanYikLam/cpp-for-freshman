# 动手任务：遍历统计总分、均分与最高分

**几分钟能做完**：40 到 50 分钟。
**交付物**：一份能编译、能跑的 `stats.cpp`，输出与「预期输出」逐字一致。

## 这个任务要做什么

成绩管理系统的第一块真正能用的东西：**给它一批成绩，它吐出三个数字**。

1. 读入 10 个成绩存进数组；
2. 用循环算出总分与最高分；
3. 均分用小数算，保留一位小数；
4. 按「总分、平均分、最高分」三行打印。

第 11 课的 `stats-04.cpp` 把这件事做完了，这次你要自己搭一遍：**两个统计各自写成函数**，`main` 里只留「读数据、调函数、打结果」。

## 预期输出

```term
$ ./stats < 10个成绩.in
请依次输入 10 个成绩：
总分：869
平均分：86.9
最高分：95
```

```term
$ ./stats < 10个相同成绩.in
请依次输入 10 个成绩：
总分：600
平均分：60.0
最高分：60
```

第二个 10 个相同成绩的情形最值得跑：最高分的循环如果写错，这里最容易看出来。

## 要点

- **两个统计函数各交回一个数**：总分交回整数，最高分也交回整数；均分在 `main` 里用小数算。
- **打擂台的擂主初值取第一个元素**，不是 0。
- **循环边界与数组长度绑在同一个常量上**：`const int N = 10;` 配 `i < N`。
- **均分要用小数算**：整数除法会把小数截掉，`869 / 10` 得到 86，不是 86.9。
- 读数据和统计可以用两个循环：先全读进来，擂台才有第一个元素当初值。

## 卡住了怎么办

按这个顺序来：

1. **读报错**：先看 `error` 那行的文件名与行号。
2. **看上面的「要点」**，五条对应五类常见错法。
3. **看 `自查清单.md`**。
4. 还是卡住，才去看 `lab/solutions/0011-array-loop-stats/stats.cpp`。

调试的笨办法比盯着屏幕推演快：在循环里打印每一轮的下标和累加结果，少算的那一格立刻现形。

## 常见现象对照

| 你看到的 | 多半是什么 |
| --- | --- |
| 总分 0 | 累加器没进循环，或者函数体里忘了写返回语句 |
| 最高分 0 | 擂主初值写了 0，而所有成绩都大于 0 时它就永远站着（替换掉第一行数据试试） |
| 最高分是 55 | 比较号写反了（`<` 换成了 `>` 的反面），留下的是最小值 |
| 总分少一个成绩 | 循环边界少了一格，比如 `i < N - 1` |
| 平均分是 86 | 整数除法：均分要用小数算 |
| 每个统计都返回 0 | 函数里 `return 0;` 忘了改成真正的结果 |
