# 本文件说明「跑对了应该看到什么」，供你自己对答案用。
# 你的程序多打几行（例如把三个成绩也打印出来）也算对——下面这些行必须出现，
# 而且数字要对。

$ ./average3 < 成绩.txt
请输入三门课的成绩（用空格或回车分开）：总分：267.5
平均分：89.2

$ ./average3 < 乱输入.txt
请输入三门课的成绩（用空格或回车分开）：这组输入不是三个数，请重新输入：总分：267.5
平均分：89.2

# 参考解只打印这两行。你的程序如果按任务书把三个成绩也打出来，形如：
#   三门成绩：92.0、88.0、87.5
# 那也是对的。这一条要看的只有两件事：
#   ① 总分的数字对（267.5）；
#   ② 平均分是一位小数、且等于总分除以 3（89.2，不是 89、也不是 89.0）。
