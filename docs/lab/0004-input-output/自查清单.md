# 自查清单：读入三门成绩算平均分

做完之后照着一条条核。**每一条都能自己验，不要凭印象打勾。**

## 一、编译与运行

- [ ] `g++ -std=c++17 -Wall -Wextra average3.cpp -o average3` 没有任何 `error`，也没有 `warning`。
- [ ] `./average3 < 成绩.txt` 能跑完，不需要手动敲字。
- [ ] `./average3 < 乱输入.txt` 也能跑完，中间不会卡住、不会直接结束。

## 二、正常输入（`成绩.txt`）

- [ ] 屏幕上出现了总分那一行，数字是 **267.5**。
- [ ] 屏幕上出现了平均分那一行，数字是 **89.2**。
- [ ] 平均分**不是** `89`，也**不是** `89.0`——这两个都说明小数在算的那一步就丢了。
- [ ] 平均分与总分对得上：267.5 ÷ 3 = 89.166…，保留一位是 89.2。
- [ ] 提示语说清了「用空格或回车分开」。（参考解不打三个成绩那一行；你要是打了，多个一两行不算错。）

## 三、乱输入（`乱输入.txt`：先 `abc`，再 `92 88 87.5`）

- [ ] 程序先回了一句话（不是直接崩掉，也不是把 `abc` 当成 0 用下去）。
- [ ] 然后重新问了一次，接受了你第二次输入。
- [ ] 最后的两个数字仍然是 **267.5** 与 **89.2**。

## 四、必须能拦住的情况

- [ ] 三个值写在一行、分成三行、中间夹很多空格——三种写法读到的三个数完全相同。
- [ ] 第一个值就不是数字（`abc 88 87`）时，程序不会打印出一组假成绩，而是重问。
- [ ] 把输入第三个成绩换成 `88`（也就是 `92 88 88`），总分变成 `268.0`、平均分变成 `89.3`（按计算器算一遍对一下）。

## 五、代码本身

- [ ] 科目数只有一个定义处（一个 `const int` 常量），没有在别处又写一遍 `3`。
- [ ] 三个成绩的类型是 `double`，不是 `int`。
- [ ] 失败之后做了两件事：复位 `cin` 的失败状态、把坏输入从队列里丢掉。
- [ ] 每个 `cin` 前面都有提示语。

## 六、交之前问自己一句

把这份程序给同宿舍的人用一次，他不看代码、只看屏幕，知道该敲什么、敲错了会怎样吗？
答不上来，就回去补提示语。
