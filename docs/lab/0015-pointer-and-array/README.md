# 动手任务：指针遍历成绩表

**几分钟能做完**：30 到 40 分钟。
**交付物**：一份能编译、能跑的 `pointerstats.cpp`，输出与「预期输出」逐字一致。

## 这个任务要做什么

第 15 课说了：`scores[i]` 与 `*(scores + i)` 是同一件事的两种写法。这次亲手把成绩表走两遍：

1. 用**指针自增**走一遍整张表，算出总分（成绩表已经在代码里了，不用读输入）；
2. 用**循环变量加 `*(p + i)`** 再走一遍，算出总分与平均分——这一遍 `p` 一直不动；
3. 两遍算出来的总分必须一模一样。

两遍都走通，你就真的看清了「指针 = 起点 + 步长」。

## 预期输出

```term
$ ./pointerstats
成绩表：88 76 95 60 82 
指针版总分：401
*(p + i) 版总分：401
*(p + i) 版平均分：80.2
```

第一行末尾有一个空格（循环里每打印一个成绩后面跟一个空格），这不影响对照。

## 要点

- **指针的起点是数组名**：`int *p = scores;` 不用写 `&`。
- **`p++` 在指针上走一个元素那么远**，`int *` 上就是 4 个字节，不是 1 个字节。
- **终点线是 `scores + n`**：那是最后一格再往后一格的位置，只用来比较，**不能解引用**。所以条件写 `p < scores + n`。
- **第二遍里 `p` 不动**：取元素写 `*(p + i)`，动的是括号里那个 `i`。
- 平均分要用小数算：`static_cast<double>(total) / n`，或者写成 `total * 1.0 / n`。

想看清指针走到哪了，最直接的办法是在循环里加一句把 `p` 和 `*p` 打出来——地址是十六进制数，但你只需要看它每轮涨了多少。

## 常见现象对照

| 你看到的 | 多半是什么 |
| --- | --- |
| 总分 0 | 循环体里取了 `*p`，但没加进累加器 |
| 总分 401 但循环跑了两次、两次都加同一个元素 | `p++` 写成了 `(*p)++`：加的是数据，不是指针 |
| 读到一个莫名其妙的数（不是成绩表里的任何一个） | 条件写成 `p <= scores + n`，最后一轮解引用了终点线 |
| `*(p + i) 版总分` 少一个成绩 | 循环条件写成 `i < n - 1`，或者起始写成 `i = 1` 配 `i < n` |
| 平均分是 80 | 整数除法：`total / n` 两个都是整数 |
