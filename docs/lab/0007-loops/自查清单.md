# 自查清单：读入并累加一批成绩

**每一条都能自己验，不要凭印象打勾。**

## 一、编译与运行

- [ ] `g++ -std=c++17 -Wall -Wextra loops.cpp -o loops` 没有任何 `error`，也没有 `warning`。
- [ ] 三组输入都能跑完，不会卡在等输入上。

## 二、逐组对输出

- [ ] `./loops < 5个成绩.in` → `共 5 个成绩，总分 433`
- [ ] `./loops < 3个成绩.in` → `共 3 个成绩，总分 253`
- [ ] `./loops < 1个成绩.in` → `共 1 个成绩，总分 88`
- [ ] 每一组都自己手加一遍，和屏幕上的数字完全一致（不是「差不多」）。

## 三、必须能应付的变化

- [ ] 自己新写一份 `4个成绩.in`（个数 4，加四个成绩），不改代码就能跑对。
- [ ] `3个成绩.in` 的总分**没有**把属于下一批的 92、88 也算进去——个数说了算。
- [ ] 把 `5个成绩.in` 里某个成绩改成带小数的（例如 `87.5`），总分跟着变对。

## 四、代码本身

- [ ] 累加器在进循环之前等于 0。
- [ ] 循环次数由读进来的那个个数决定，代码里没有写死 `5`。
- [ ] 循环体里两件事都做了：读一个成绩、加进总分。
- [ ] 循环变量每一轮都变（不会转不停）。
- [ ] 起始值与边界配成一套：写 `i = 1` 就用 `i <= n`，写 `i = 0` 就用 `i < n`。

## 五、交之前问自己一句

「如果老师明天把这批成绩换成 50 个，我要改几行？」答案是 0 行——改的是输入文件，不是代码。
