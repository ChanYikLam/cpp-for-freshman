# 实验一任务：从空白文件写出一个能算的程序

**这一课是验收课**：到这里你已经知道怎么写、怎么编译、怎么读报错，但还没有独立走完过一整条。
这次给自己出一个小题目，**从空白文件写到一个能跑的程序**。

**交付物**：一份自己写的 `temp.cpp`（或 `average3.cpp`，两个题目挑一个），
编译无警告、输出与预期一致、代码不少于 35 行（含注释与空行）。

**完整任务书**：同名的课件页 `实验一：跑通编译运行循环`（`lessons/0005-exp-1-first-program.html`）
里有验收标准、自查清单与「最可能卡在哪」。

## 两个题目，挑一个

### 题目 A · 体温换算（推荐）

读入一个华氏温度，换算成摄氏度打印出来，保留一位小数。

换算公式：

```text
摄氏 = (华氏 - 32) × 5 / 9
```

### 题目 B · 三门成绩算平均分

读入三门课的成绩，打印总分与平均分（一位小数）。

## 文件清单

| 文件 | 是什么 |
| --- | --- |
| `temp.cpp` | **留白**的起始文件：只有骨架和三处 `TODO`。题目 A 从这里开始 |
| `体温输入.txt` | 题目 A 的输入：`98.6` |
| `另一个体温.txt` | 题目 A 的输入：`104` |
| `预期输出.txt` | 题目 A 该打印什么 |
| `自查清单.md` | 交之前照着一整条条核 |

选题目 B 的同学，输入文件用 `98.6`/`104` 换成三个成绩即可（用空格或回车分开），
其余步骤一样。

## 怎么编译、怎么跑

```sh
g++ -std=c++17 -Wall -Wextra temp.cpp -o temp
```

```sh
./temp < 体温输入.txt
./temp < 另一个体温.txt
```

**编译不带 `-Wall -Wextra` 不算完成**：这一课的验收要求「编译无警告」，警告只有带上这两个选项才看得见。

### Dev-C++ 用户对照

| 命令行里做的 | Dev-C++ 里点的 |
| --- | --- |
| 新建 `temp.cpp` | 文件 → 新建 → 源代码，写完 Ctrl+S 存成 `.cpp` |
| `g++ ... -o temp` | 按 **F11**（编译并运行） |
| 看编译警告 | F11 之后下方那一栏；警告在「工具 → 编译选项」里勾上「显示更多警告」才全出来 |
| `./temp < 体温输入.txt` | 做不到，手动敲：F11 之后在弹出窗口里敲 `98.6` 回车 |

## 预期输出（题目 A）

```term
$ ./temp < 体温输入.txt
请输入体温（华氏度，例如 98.6）：华氏 98.6 度 = 摄氏 37.0 度
```

```term
$ ./temp < 另一个体温.txt
请输入体温（华氏度，例如 98.6）：华氏 104.0 度 = 摄氏 40.0 度
```

自己按计算器核一遍：(98.6 − 32) × 5 ÷ 9 = 37.0。

## 卡住了怎么办

按这个顺序来，**不要一上来就找答案**：

1. **读报错**：文件名、行号、`^` 指着什么。
2. **看这节课的课件**：`0001`、`0002`、`0003`、`0004` 四课里都有现成的形状可以借鉴。
3. **看 `自查清单.md`**。
4. 还是卡住，才去看 `lab/solutions/exp-1-first-program/temp.cpp`。

## 常见现象对照

| 你看到的 | 多半是什么 |
| --- | --- |
| 摄氏打出 37，没有小数 | 5 / 9 先按整数算成了 0，或者用了 int 接收结果 |
| 摄氏打出 66.6 | 忘了减 32 再乘 |
| 摄氏打出 37.0 但 104 那组不对 | 分母或系数写成了整数 |
| 提示语和结果挤在一行、看不清 | 提示语后面没有换行，这是正常的；也可以先打印一个换行 |
| 窗口一闪就没了（Windows） | 程序崩了，或者没读到输入 |
