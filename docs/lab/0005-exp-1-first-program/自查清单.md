# 自查清单：实验一 · 跑通编译运行循环

交之前逐条核。**每条都能自己验。**

## 一、编译

- [ ] `g++ -std=c++17 -Wall -Wextra temp.cpp -o temp` 退出码是 0。
- [ ] 输出里**没有** `error`。
- [ ] 输出里**没有** `warning`（带 `-Wall -Wextra` 也没有）。
- [ ] 源文件里没有把编辑器显示的行号一起拷进去。

## 二、运行与输出

- [ ] `./temp < 体温输入.txt` 打印一行，摄氏 **37.0**。
- [ ] `./temp < 另一个体温.txt` 打印一行，摄氏 **40.0**。
- [ ] 两个数字都自己按计算器核过：(98.6 − 32) × 5 ÷ 9、(104 − 32) × 5 ÷ 9。
- [ ] 小数位是**一位**，不是一长串。

## 三、验证「编译运行循环」真的立起来了

- [ ] 故意删掉一个分号，重新编译，**说出**报错指的是哪个文件、哪一行。
- [ ] 把分号补回去，重新编译运行，输出恢复。
- [ ] 把输入改成 `100`，程序给出的摄氏度与手算一致。

## 四、代码与交付物

- [ ] 代码不少于 35 行（含注释与空行）。
- [ ] 输入有提示语，说清了要输入什么、什么格式。
- [ ] 用到的量有名字（不是一串裸数字），换算系数至少有一个被写成小数。
- [ ] 文件名叫 `temp.cpp`（或自己定的名字），是个 `.cpp` 纯文本文件。

## 五、收尾

- [ ] 把这一份程序留好——实验三还会用同样的方式交东西。
- [ ] 说得出这条循环的四步：写源文件 → 编译 → 运行 → 看输出改源文件。
