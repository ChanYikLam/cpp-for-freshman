# 实验二任务：存下并统计一批成绩

**这一课是验收课**：单个语法点都学过了，现在把它们串成成绩管理系统的第一个可用版本。

**交付物**：一份自己写的 `scorestats.cpp`，能存 10 个成绩、算出总分、平均分与最高分；
编译无警告、输出与预期一致；代码不少于 40 行（含注释与空行）。

**完整任务书**：同名的课件页 `实验二：存下并统计一批成绩`（`lessons/0012-exp-2-score-storage.html`）
里有验收标准、自查清单与「最可能卡在哪」。

## 这个程序要做出什么

1. 用一个数组存下 **10 个成绩**（个数用常量表示，不许在代码里散着写数字）；
2. 第一个循环把 10 个成绩读进数组；
3. 第二个循环算出总分与最高分；
4. 均分用小数算，保留一位小数；
5. 按「总分、平均分、最高分」三行打印。

**两个统计各自写成函数**，`main` 里只留「读数据、调函数、打结果」。

## 卡住了怎么办

按这个顺序来：

1. **读报错**：文件名、行号、那一行的上一行。
2. **看第 10、11 课**（`0010`、`0011`）：数组与遍历统计的形状都在那里。
3. **看 `自查清单.md`**。
4. 还是卡住，才去看 `lab/solutions/exp-2-score-storage/scorestats.cpp`。

**算错时不要直接改代码**：在循环里打印每一轮的下标与累加结果，先看清哪一格不对。

## 常见现象对照

| 你看到的 | 多半是什么 |
| --- | --- |
| 数组开成 5 个却读 10 个 | 越界写：读第九、第十个成绩时写到了数组外面 |
| 平均分 86 | 整数除法：均分要用小数算 |
| 最高分 0 | 擂主初值写了 0 |
| 最高分是 55 | 比大小的方向写反了，留下的是最小值 |
| 总分少一个成绩 | 循环边界少一格 |
| 结果不对就去改算法 | 先用打印中间值定位，改之前先知道错在哪一步 |
