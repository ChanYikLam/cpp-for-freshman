# 自查清单：遍历统计总分、均分与最高分

**每一条都能自己验。**

## 一、编译与运行

- [ ] `g++ -std=c++17 -Wall -Wextra stats.cpp -o stats` 没有任何 `error`，也没有 `warning`。
- [ ] 三组输入都能跑完。

## 二、逐组对输出

- [ ] `./stats < 10个成绩.in` → `总分：869` / `平均分：86.9` / `最高分：95`
- [ ] `./stats < 10个相同成绩.in` → `总分：600` / `平均分：60.0` / `最高分：60`
- [ ] `./stats < 另一批10个.in` → `总分：779` / `平均分：77.9` / `最高分：100`
- [ ] 每一组都自己手算一遍（最高分不用算，扫一眼就能找到），与屏幕上的数字一致。

## 三、必须能拦住的情况

- [ ] 十个成绩全是同一个数时，最高分等于那个数（擂主初值没写错）。
- [ ] 最高分出现在第一个位置时也对（擂主就是它自己，循环一次都不换人）。
- [ ] 最高分出现在最后一个位置时也对（循环走到了最后一格）。
- [ ] 把第一个成绩改成 100 再跑：最高分跟着变成 100，总分也跟着变。
- [ ] `./stats < 第一个不是数字.in`：程序不会打出一组假成绩；它要么停下，要么按你自己写的失败处理走——把实际现象写下来，对照 `10个成绩.in` 的结果说明差在哪。

## 四、代码本身

- [ ] 两个统计各自在一个函数里，函数头上有返回类型，函数体里有 `return`。
- [ ] 数组长度只有一个定义处（一个 `const int` 常量），声明与两个循环都用它。
- [ ] 擂主初值取的是数组的第一个元素，不是 0。
- [ ] 累加器在进循环之前等于 0。
- [ ] 均分用了小数（除数或被除数至少一个是小数）。
- [ ] 循环条件是 `i < N`，最后一轮下标正好是 `N - 1`。

## 五、交之前问自己一句

「如果这批成绩换成 20 个，我要改几行？」答案应该只有一处——那个常量。
