# 先读我（30 秒）

这是一套 **C++ 零基础入门课程**，写给计算机专业大一新生，从「第一次写出 Hello World」讲到「指针与数组配合处理一批数据」，一共 18 章。

## 现在做两件事

**第一步：打开课程**

    进入 docs 文件夹  →  双击 index.html

就这样，不用联网、不用装任何东西。双击之后浏览器里会出现课程首页，18 章的目录都在上面，点哪章看哪章。

> ⚠️ 双击 `index.html`，**不要**双击别的 `.txt` 或 `.md` 文件——那些是说明文字，不是课程本体。
> 如果双击后浏览器没反应，右键选「打开方式 → 浏览器」。

**第二步：读完这份说明后，去看 `3-学习指南.md`**

那份里写了怎么学、每章有哪些东西、卡住了先做什么。看完再开始，能省不少弯路。

## 这个文件夹里有什么

    1-先读我.md        ← 你正在看的这份
    2-建议用电脑打开.md  为什么一定要在电脑上学（很重要，别跳）
    3-学习指南.md      怎么用这套课（务必读）
    README.md        课程的完整说明
    docs/            ★ 课程本体，全部在这里
    dist/            打包产物，和你手上这个压缩包是同一个东西，可以不管

## 看不懂名词怎么查

课程带两份术语表，讲的是同一批词：

- **完全没接触过计算机** → 先看**大白话版**：`docs/cpp-basics/GLOSSARY-EASY.html`
  每个词都用生活里的东西打比方（比如「指针 = 一张写着门牌号的纸条」）。
- **想确认准确说法** → 看**规范版**：`docs/cpp-basics/GLOSSARY.html`

两边的页面上也互相有链接，随时可以换着看。

## 一句话提醒

这套课**必须边看边在电脑上敲代码**。只看不敲，指针那一章一定过不去——那是大一第一学期最多人卡住的地方。
