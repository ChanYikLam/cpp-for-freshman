# 建议用电脑打开这门课（别只用手机看）

## 说在最前面

手机上**可以看**：页面是响应式的，手机浏览器打开也能读，通勤路上翻两章没问题。

但要**学**这门课，请用电脑。原因只有一个，而且很硬：

> **手机编不了 C++ 程序。**

这门课每一章都有代码要你亲手跑。写源文件、敲 `g++` 编译、运行、看输出、读报错、改对——这条循环是整门课的主线。手机能让你「看完」，但没法让你「学会」：你没有地方敲代码，也就没有机会撞上那屏红字，而没有撞过报错的人，下一章就会卡住。

## 用电脑该怎么学

1. 把整个文件夹放到电脑上（解压到桌面就行）。
2. 双击 `docs/index.html`，在浏览器里看课。
3. **另开一个窗口**：终端（macOS 是「终端」，Windows 是 PowerShell 或 MSYS2 终端），用来写代码、编译、运行。
4. 左边看课、右边敲代码，边看边敲。

装编译环境不用提前操心，**第 1 章会手把手带你装**，macOS 和 Windows 都给了对照说明。

## 只有手机、没有电脑怎么办

先把前几章**读一遍**、把术语表翻一翻，心里有个数。等你手边有电脑了再回来动手敲——但请不要跳过动手那一步就往下学，后面会越看越虚。

## 顺带三件事

- **别只解压一部分**：整个文件夹一起解压，`docs` 里那些样式和脚本是配套的，缺了页面会变成没排版的裸文字。
- **别改文件名和目录结构**：课程内部的链接是按现在的结构写好的，改名字会导致点不动。想另存代码，复制出去再改。
- **手机上分享给同学没问题**：把这个压缩包直接转发就是完整的，对方解压后双击 `docs/index.html` 就能看。
